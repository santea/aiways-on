# 07. 인증/보안 처리

## 마이그레이션 원칙 (SDP → SDL)

- ✅ SDP 라이브러리 → SDL 모듈 매핑
- ✅ SDP 라이브러리 내부 구현을 몰라도 구 소스의 로직만 보고 SDL 향으로 마이그레이션 가능
- ✅ 구 소스에서 SDP 사용 방식 확인
- ✅ SDL 모듈에서 동일 기능 찾기
- ✅ 테스트를 통해 기능 동등성 확인

### SDL 로그인 확인 (이미 적용됨: LoginController, AdLoginController, MfaLoginController)

**구 소스 (SDP)**:

```java
@Controller
public class LoginController {
    
    @Autowired
    private IIdentityManager identityManager;
    
    @RequestMapping("/login")
    public String login(@RequestParam String userId, @RequestParam String password, Model model) {
        boolean authenticated = identityManager.authenticate(userId, password);
        if (authenticated) {
            return "redirect:/main";
        } else {
            model.addAttribute("error", "로그인 실패");
            return "login/login";
        }
    }
}
```

**신규 DEMO (SDL)**:

```java
@RestController
public class LoginController {
    
    @Autowired
    private LoginService loginService;
    
    @PostMapping("/login")
    public ResponseEntity<LoginResponse> login(@RequestBody LoginRequest request) {
        LoginResponse response = loginService.login(request);
        return ResponseEntity.ok(response);
    }
}
```

### SDL 보안 관리 확인 (이미 적용됨: HTMLCharacterEscapes, RestExceptionHandler)

**구 소스 (SDP)**:

```java
@Controller
public class SampleController {
    
    @RequestMapping("/sample")
    public String sample(@RequestParam String input, Model model) {
        // XSS 방지 처리 필요
        String safeInput = escapeHtml(input);
        model.addAttribute("input", safeInput);
        return "sample/sample";
    }
}
```

**신규 DEMO (SDL)**:

```java
@RestController
public class SampleController {
    
    @GetMapping("/sample")
    public ResponseEntity<SampleResponse> sample(@RequestParam String input) {
        // HTMLCharacterEscapes에서 자동 XSS 방지 처리
        SampleResponse response = new SampleResponse(input);
        return ResponseEntity.ok(response);
    }
}
```

### SDL 시스템 관리 확인 (이미 적용됨: CacheConfig, RedisConfig)

**구 소스 (SDP)**:

```java
@Controller
public class SampleController {
    
    @Autowired
    private ICacheManager cacheManager;
    
    @RequestMapping("/sample")
    public String sample(Model model) {
        Object data = cacheManager.get("sample");
        if (data == null) {
            data = loadSampleData();
            cacheManager.put("sample", data);
        }
        model.addAttribute("data", data);
        return "sample/sample";
    }
}
```

**신규 DEMO (SDL)**:

```java
@RestController
public class SampleController {
    
    @Autowired
    private CacheService cacheService;
    
    @GetMapping("/sample")
    public ResponseEntity<SampleResponse> sample() {
        SampleResponse response = cacheService.get("sample", () -> loadSampleData());
        return ResponseEntity.ok(response);
    }
}
```
