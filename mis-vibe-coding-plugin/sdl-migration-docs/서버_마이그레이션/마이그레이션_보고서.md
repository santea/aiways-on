## 4. 변환 작업 내용

### 4.1 공통 변환 작업

#### 4.1.1 Java 버전 업그레이드 (Java 7 → Java 17)

- **작업 내용**:
  - 람다 표현식으로 변환
  - Stream API 활용
  - Optional 사용
  - Date/Time API (java.time)로 변경
  - try-with-resources 적용
- **난이도**: 중간
- **예상 공수**: 3일

#### 4.1.2 Spring Framework 업그레이드 (Spring MVC 3.0.5 → Spring Boot 3.5.8)

- **작업 내용**:
  - XML 설정 → Java Config/Annotation으로 변환
  - `@Controller` → `@RestController` (REST API)
  - `@RequestMapping` → `@GetMapping/@PostMapping` 등
  - `ModelAndView` → `ResponseEntity`로 변환
  - Spring Boot AutoConfiguration 활용
- **난이도**: 높음
- **예상 공수**: 5일

#### 4.1.3 iBatis2 → MyBatis3 변환

- **작업 내용**:
  - `SqlMapClient` → `SqlSessionFactory`로 변경
  - `SqlMapConfig.xml` → `mybatis-config.xml`로 변환
  - iBatis2 쿼리 문법 → MyBatis3 문법으로 변환
  - `queryForList()` → `selectList()`로 변경
  - `queryForObject()` → `selectOne()`로 변경
  - `insert()` → `insert()` (호출 방식 변경)
- **난이도**: 높음
- **예상 공수**: 7일

#### 4.1.4 JSP → Vue.js 3 SPA 변환

- **작업 내용**:
  - JSP 템플릿 → Vue.js 컴포넌트로 변환
  - JSTL 태그 → Vue.js 디렉티브로 변환
  - 서버 사이드 렌더링 → 클라이언트 사이드 렌더링
  - REST API 호출 (Axios)로 데이터 전송
  - Vue Router로 페이지 라우팅
- **난이도**: 매우 높음
- **예상 공수**: 15일

#### 4.1.5 보안 변환 (Spring Security 3.0.3 → JWT)

- **작업 내용**:
  - Spring Security XML 설정 → JWT 기반 인증으로 변환
  - 세션 기반 인증 → 토큰 기반 인증
  - `AuthenticationInterceptor` 구현
  - `AuthorizationInterceptor` 구현
  - SAML 인증 유지 (OneLogin)
- **난이도**: 높음
- **예상 공수**: 5일

#### 4.1.6 데이터베이스 연동 변환

- **작업 내용**:
  - 다중 데이터베이스 연동 → 단일 데이터베이스 연동 (또는 다중 연동 유지)
  - HikariCP 설정
  - MyBatis Mapper 경로 설정
  - 트랜잭션 매니저 설정
- **난이도**: 중간
- **예상 공수**: 3일

### 9.2 SDP 아키텍처

SDP(표준개발플랫폼)는 3계층 아키텍처를 기반으로 합니다:

```
┌─────────────────────────────────────────────────────────┐
│                  Presentation Layer                     │
│                    (Controller)                         │
│  - 사용자 요청 처리                                      │
│  - 비즈니스 로직 호출                                    │
│  - 응답 생성                                            │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│                   Business Layer                        │
│                     (Service)                           │
│  - 비즈니스 로직 구현                                    │
│  - 트랜잭션 관리                                        │
│  - DAO 호출                                             │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│         Persistence Layer/Integration Layer             │
│                      (DAO)                              │
│  - DB 연동 (iBATIS2)                                    │
│  - Query 실행                                           │
│  - 데이터 변환                                          │
└─────────────────────────────────────────────────────────┘
```

**SDP 주요 특징:**
- Spring 3.0 기반
- iBATIS2 사용
- @Inject Annotation 사용
- @Service, @Repository Annotation 사용
- AbstractDAO 상속
- @Transactional 사용

### 9.3 SDP Tutorial (Entity, Service, Implement, Dao 작성)

SDP에서는 다음과 같은 순서로 비즈니스 로직을 작성합니다:

#### Entity 클래스 작성

Table 정보를 바탕으로 Domain 클래스를 생성합니다.

```java
// SDP Entity 클래스
public class Drama implements Serializable {

    private static final long serialVersionUID = 1L;
    private String dramaId;
    private String title;
    private List<DramaCharacter> dramaCharacter = new ArrayList<DramaCharacter>(0);
    
    public String getDramaId() {
        return dramaId;
    }

    public void setDramaId(String dramaId) {
        this.dramaId = dramaId;
    }
    
    public List<DramaCharacter> getDramaCharacter() {
        return dramaCharacter;
    }

    public void setDramaCharacter(List<DramaCharacter> dramaCharacter) {
        this.dramaCharacter = dramaCharacter;
    }
}
```

#### Service 클래스 작성

Service Interface 클래스를 작성합니다. Controller에서 Business Method를 호출하는 데 사용되며 signature만 작성하고 method의 구현은 Implements 클래스에서 작성합니다.

```java
// SDP Service Interface
public interface DramaService {

    ISearchResults<Drama> getPagingList(SearchVO searchVO);

    Drama get(String dramaId);

    void save(Drama drama) throws Exception;

    void update(Drama drama) throws Exception;

    void remove(String dramaId);
}
```

#### Implement 클래스 작성

DramaService의 구현 클래스인 DramaServiceImpl 클래스를 추가합니다. 비즈니스 로직은 이 단계에서 구현합니다.

```java
// SDP Service Implement
@Service                         // @Service 어노테이션을 설정합니다.
public class DramaServiceImpl implements DramaService {

    // CRUD 실행을 위해, DAO Bean을 조회할 수 있도록 합니다.
    @Inject
    DramaDao dramaDao;

    @Inject
    DramaCharacterDao dramaCharacterDao;

    // Unique한 ID를 생성하기위해 공통 서비스로 제공되고 있는 IDGenService를 조회합니다.
    @Inject
    @Named("UUIdGenerationService")
    IdGenService idGenerationService;

    public ISearchResults<Drama> getPagingList(SearchVO searchVO) {
        return this.dramaDao.getPagingList(searchVO);
    }

    public Drama get(String dramaId) {
        Drama drama = new Drama();
        drama = this.dramaDao.get(dramaId);
        drama.setDramaCharacter(dramaCharacterGetList(dramaId));
        return drama;
    }

    private List<DramaCharacter> dramaCharacterGetList(String dramaId) {
        return dramaCharacterDao.getList(dramaId);
    }
    
    // 트랜잭션 관리를 위한 어노테이션을 추가합니다.
    @Transactional(rollbackFor = { Exception.class }, propagation = Propagation.REQUIRED)
    public void save(Drama drama) throws Exception {

        String dramaId = idGenerationService.getNextStringId();
        drama.setDramaId(dramaId);
        
        dramaDao.save(drama);
    }
    
    @Transactional
    public void remove(String dramaId) {

        this.dramaCharacterDao.remove(dramaId);
        this.dramaDao.remove(dramaId);
    }
}
```

#### Dao 클래스 작성

DB와 연결하여 Query를 실행하기 위해, DramaDao, DramaCharacterDao 클래스를 추가합니다. 각각의 DAO를 작성할 수 있도록 AbstractDAO를 상속하여 작성합니다.

```java
// SDP DAO
@Repository("dramaDao")                         // @Repository 어노테이션을 설정합니다.
public class DramaDao extends AbstractDAO<Drama> {

    public DramaDao() {
        super(Drama.class);
    }

    // 페이지당 보여줄 데이터수를 설정합니다.
    @Value("#{contextProperties['dramaPageSize'] ?: 3}")
    int pageSize;

    // 네비게이션에 보여줄 페이지수를 설정합니다.
    @Value("#{contextProperties['dramaPageUnit'] ?: 10}")
    int pageUnit;

    // AbstractDAO에서 제공하는 기능을 이용하여 쿼리를 실행합니다.
    public ISearchResults<Drama> getPagingList(SearchVO searchVO) {

        String searchCondition = StringUtil.null2str(searchVO.getSearchCondition());
        String searchKeyword = StringUtil.null2str(searchVO.getSearchKeyword());

        Map<String, Object> arg = new HashMap<String, Object>();
        arg.put("searchCondition", searchCondition);
        arg.put("searchKeyword", searchKeyword);

        ISearchResults<Drama> searchResult = selectBy(arg, searchVO.getPageIndex(), pageSize, pageUnit, "");
        return searchResult;
    }
}
```

## 11. SDP → SDL 변환 매핑 분석

### 11.1 아키텍처 비교

| 구분 | SDP | SDL | 변경 필요 |
|------|-----|-----|-----------|
| **Spring 버전** | 3.0 | 3.5.8 | ✅ |
| **ORM** | iBATIS2 | MyBatis 3.x | ✅ |
| **DI Annotation** | @Inject | @Autowired | ✅ |
| **DAO** | AbstractDAO 상속 | @Mapper | ✅ |
| **응답 형식** | Model + View | JSON | ✅ |
| **트랜잭션** | @Transactional | @Transactional | ⚠️ 설정 확인 |

### 11.2 기능 매핑

| SDP 기능 | SDL 기능 | 변환 방법 |
|----------|----------|-----------|
| 메뉴 관리 | 메뉴 관리 | MenuController → MenuController |
| 권한 관리 | 권한 관리 | IAuthorizationManager → AuthorizationInterceptor |
| 시스템 로깅 | 이력 관리 | LoggingInterceptor → LoggingInterceptor |
| 파일 관리 | 파일 서비스 | FileManager → FileManagerService |
| 게시판 관리 | 게시판 서비스 | BoardController → PostController |
| 결재 관리 | 결재 서비스 | ApprovalController → ApprovalController |

### 11.3 코드 변환 예시

#### @Inject → @Autowired

```java
// SDP
@Inject
private DramaDao dramaDao;

// SDL
@Autowired
private DramaMapper dramaMapper;
```

#### AbstractDAO → @Mapper

```java
// SDP
@Repository("dramaDao")
public class DramaDao extends AbstractDAO<Drama> {
    public ISearchResults<Drama> getPagingList(SearchVO searchVO) {
        return selectBy(arg, searchVO.getPageIndex(), pageSize, pageUnit, "");
    }
}

// SDL
@Mapper
public interface DramaMapper {
    List<Drama> getPagingList(SearchVO searchVO);
}
```

#### ISearchResults → List

```java
// SDP
public ISearchResults<Drama> getPagingList(SearchVO searchVO) {
    return this.dramaDao.getPagingList(searchVO);
}

// SDL
public List<Drama> getPagingList(SearchVO searchVO) {
    return this.dramaMapper.getPagingList(searchVO);
}
```
