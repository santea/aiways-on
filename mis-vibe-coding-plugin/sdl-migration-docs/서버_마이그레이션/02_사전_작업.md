### ② 신규 DEMO 서버 소스 분석

- **구조**: Spring Boot 3.5.8 + REST API + Vue.js + MyBatis 3.x
- **패턴**: Controller → Service → Mapper (MyBatis 3.x)
- **DB 연동**: Tibero + MyBatis XML Mapper
- **공통 처리**: SDL 프레임워크 6.1.1 (인증, 권한, 게시판, 이메일, 파일, 배치)
- **DB 스키마**: SDL 표준 테이블 구조 (TN_CF_USER, TN_CF_POST, TC_CF_COMM_CODE, TN_CF_ATTACH_FILE 등)
