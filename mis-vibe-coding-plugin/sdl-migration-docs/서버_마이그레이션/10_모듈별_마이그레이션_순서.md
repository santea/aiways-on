## 4. 모듈별 마이그레이션 순서

### P0 (핵심 모듈) - 우선 진행

1. **사용자 관리 (user)**
   - Controller: `PortalUserController` → `UserController`
   - Service: `PortalUserService` → `UserService`
   - Mapper: `PortalUserDAO` → `UserMapper`
   - DTO: `PortalUser` → `UserDto`
   - DB: `T_USER` → `TN_CF_USER`

2. **시스템 관리 (system)**
   - Controller: `PortalSystemController` → `SystemController`
   - Service: `PortalSystemService` → `SystemService`
   - Mapper: `PortalSystemDAO` → `SystemMapper`
   - DTO: `CommonCode` → `CommCodeDto`
   - DB: `T_COMM_CODE` → `TC_CF_COMM_CODE`

3. **파일 관리 (fms)**
   - Controller: `FmsController` → `FileController`
   - Service: `FmsService` → `FileService`
   - Mapper: `FmsDAO` → `FileMapper`
   - DTO: `Fms` → `FileDto`
   - DB: `T_ATTACH_FILE` → `TN_CF_ATTACH_FILE`

4. **비밀번호 관리 (password)**
   - Controller: `PasswordController` → `PasswordController`
   - Service: `PasswordService` → `PasswordService`
   - Mapper: `PasswordDAO` → `PasswordMapper`
   - DTO: `PwdReqUser` → `PasswordDto`
   - DB: `T_PWD_REQ` → `TN_CF_USER` (통합)
