# 05. 공통 설정

## 마이그레이션 원칙 (SDP → SDL)

- ✅ Spring 3.0 → Spring Boot 3.5.8 의존성 변경
- ✅ Oracle → Tibero 데이터베이스 설정 변경
- ✅ iBATIS2 → MyBatis 3.x 설정 변경
- ✅ @ExceptionHandler → @RestControllerAdvice 변환
- ✅ HandlerInterceptor → HandlerInterceptor (동일)

### 2.2 공통 모듈

#### 2.2.1 예외 처리

```java
// 기존: @ExceptionHandler
// 변경: @RestControllerAdvice + @ExceptionHandler

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(Exception.class)
    public ResponseEntity<ErrorResponse> handleException(Exception e) {
        ErrorResponse error = new ErrorResponse();
        error.setCode("500");
        error.setMessage(e.getMessage());
        return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR).body(error);
    }
}
```

#### 2.2.2 인터셉터 설정

```java
// 기존: HandlerInterceptor
// 변경: HandlerInterceptor (동일)

@Configuration
public class WebConfig implements WebMvcConfigurer {

    @Autowired
    private AuthorizationInterceptor authorizationInterceptor;

    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        registry.addInterceptor(authorizationInterceptor)
                .addPathPatterns("/api/**")
                .excludePathPatterns("/api/noauth/**");
    }
}
```
