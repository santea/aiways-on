# 03. SDP 라이브러리 분석

## 마이그레이션 원칙 (SDP → SDL)

- ✅ SDP 라이브러리 내부 구현을 몰라도 구 소스의 로직만 보고 SDL 향으로 마이그레이션 가능
- ✅ 구 소스에서 SDP 사용 방식 확인
- ✅ SDL 모듈에서 동일 기능 찾기
- ✅ 테스트를 통해 기능 동등성 확인

### SDP 라이브러리 기능 예

SDP(표준개발플랫폼) 라이브러리는 다음과 같은 기능을 제공합니다:

| No  | 기능명         | 기능상세                                        |
| --- | -------------- | ----------------------------------------------- |
| 1   | 메뉴 관리      | 메뉴관리, 메뉴활용률 출력                       |
| 2   | 권한 관리      | 사용자관리, 권한그룹, SSO인증                   |
| 3   | 시스템 로깅    | 시스템 로그, 배치 로그, 메뉴 활용도             |
| 4   | 파일 관리      | 파일 업로드/다운로드, 파일 다운로드 이력        |
| 5   | 게시판 관리    | 게시판 관리, 게시글 관리, 댓글 관리             |
| 6   | 결재 관리      | Knox 결재 연계, 결재 상신, 결재 상황 조회       |
| 7   | 메일 관리      | Knox 메일 연계, 메일 발송, 메일 상태 조회       |
| 8   | 공통 코드 관리 | 공통 코드 관리, 공통 코드 조회                  |
| 9   | 사용자 관리    | 사용자 관리, 사용자 정보 조회                   |
| 10  | 역할 관리      | 역할 관리, 역할-사용자 관리, 역할-업무그룹 관리 |
| 11  | 업무그룹 관리  | 업무그룹 관리, 업무그룹-사용자 관리             |

### 예시

**구 소스 (SDP)**:

```java
@Autowired
private IAuthorizationManager authorizationManager;

public boolean checkAccess(String userId, String resourceId) {
    return authorizationManager.hasPermission(userId, resourceId);
}
```

**신규 DEMO (SDL)**:

```java
// SDL은 AuthorizationInterceptor에서 URL 기반 자동 권한 체크

// 메뉴 관리에서 권한 설정만 하면 됨
```

## SDP 라이브러리 패키징 영역

구 운영 소스에서 SDP 라이브러리로 패키징된 부분은 소스 코드로 확인할 수 없습니다:

| SDP 라이브러리    | 기능                               | 확인 방법              |
| ----------------- | ---------------------------------- | ---------------------- |
| sdp-identity      | 인증 (로그인, 로그아웃, 세션 관리) | JAR 파일 (소스 미공개) |
| sdp-authorization | 권한 (메뉴 접근, 기능 권한)        | JAR 파일 (소스 미공개) |
| sdp-board         | 게시판 (게시글, 댓글, 첨부파일)    | JAR 파일 (소스 미공개) |
| sdp-approval      | 결재 (결재 요청, 승인, 반려)       | JAR 파일 (소스 미공개) |
| sdp-email         | 이메일 (메일 발송, 템플릿)         | JAR 파일 (소스 미공개) |
| sdp-common        | 공통 (유틸리티, 공통 기능)         | JAR 파일 (소스 미공개) |

SDL 프레임워크에서는 이 기능들이 SDL 모듈로 제공되어 있어서 확인 가능합니다.
