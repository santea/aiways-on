### 통합 테스트

**구 소스 (SDP)**:

```java
@RunWith(SpringJUnit4ClassRunner.class)
@ContextConfiguration(locations = {"classpath:spring/context.xml"})
@WebAppConfiguration
public class SampleControllerTest {
    
    @Autowired
    private WebApplicationContext wac;
    
    private MockMvc mockMvc;
    
    @Before
    public void setup() {
        this.mockMvc = MockMvcBuilders.webAppContextSetup(this.wac).build();
    }
    
    @Test
    public void testSample() throws Exception {
        mockMvc.perform(get("/sample"))
            .andExpect(status().isOk())
            .andExpect(view().name("sample/sample"));
    }
}
```

**신규 DEMO (SDL)**:

```java
@SpringBootTest
@AutoConfigureMockMvc
class SampleControllerTest {
    
    @Autowired
    private MockMvc mockMvc;
    
    @Test
    void testSample() throws Exception {
        mockMvc.perform(get("/sample"))
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.data").value("sample data"));
    }
}
```

```java
// 자동화 테스트 (Selenium)
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
class SampleE2ETest {
    
    @Autowired
    private TestRestTemplate restTemplate;
    
    @LocalServerPort
    private int port;
    
    @Test
    void testSample() {
        String url = "http://localhost:" + port + "/sample";
        ResponseEntity<SampleResponse> response = restTemplate.getForEntity(url, SampleResponse.class);
        assertEquals(HttpStatus.OK, response.getStatusCode());
        assertEquals("sample data", response.getBody().getData());
    }
}
```
