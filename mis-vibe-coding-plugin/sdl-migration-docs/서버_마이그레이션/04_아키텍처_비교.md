# 04. 아키텍처 비교

## 마이그레이션 원칙 (SDP → SDL)

- ✅ Spring 3.0 → Spring Boot 3.5.8 변환
- ✅ iBATIS2 → MyBatis 3.x 변환
- ✅ @Inject → @Autowired 변환
- ✅ AbstractDAO → @Mapper 변환
- ✅ Model + View → JSON 응답 변환

## SDP 아키텍처

SDP(표준개발플랫폼)는 3계층 아키텍처를 기반으로 합니다:

```
┌─────────────────────────────────────────────────────────┐
│                  Presentation Layer                     │
│                    (Controller)                         │
│  - 사용자 요청 처리                                      │
│  - 비즈니스 로직 호출                                    │
│  - 응답 생성                                            │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│                   Business Layer                        │
│                     (Service)                           │
│  - 비즈니스 로직 구현                                    │
│  - 트랜잭션 관리                                        │
│  - DAO 호출                                             │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│         Persistence Layer/Integration Layer             │
│                      (DAO)                              │
│  - DB 연동 (iBATIS2)                                    │
│  - Query 실행                                           │
│  - 데이터 변환                                          │
└─────────────────────────────────────────────────────────┘
```

**SDP 주요 특징:**
- Spring 3.0 기반
- iBATIS2 사용
- @Inject Annotation 사용
- @Service, @Repository Annotation 사용
- AbstractDAO 상속
- @Transactional 사용

## SDL 아키텍처

SDL 프레임워크도 3계층 아키텍처를 기반으로 합니다:

```
┌─────────────────────────────────────────────────────────┐
│                  Presentation Layer                     │
│                    (Controller)                         │
│  - REST API 요청 처리                                   │
│  - 비즈니스 로직 호출                                    │
│  - JSON 응답 생성                                       │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│                   Business Layer                        │
│                     (Service)                           │
│  - 비즈니스 로직 구현                                    │
│  - 트랜잭션 관리                                        │
│  - Mapper 호출                                          │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│         Persistence Layer/Integration Layer             │
│                     (Mapper)                            │
│  - DB 연동 (MyBatis 3.x)                                │
│  - Query 실행                                           │
│  - 데이터 변환                                          │
└─────────────────────────────────────────────────────────┘
```

**SDL 주요 특징:**
- Spring Boot 3.5.8 기반
- MyBatis 3.x 사용
- @Autowired Annotation 사용
- @Service, @Mapper Annotation 사용
- @Transactional 사용
